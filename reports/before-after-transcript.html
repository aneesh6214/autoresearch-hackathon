Same Question, Different Tutor Policy

Before and After: Autoresearch-Optimized Tutoring Behavior

This comparison uses the same final-eval student question. The baseline tutor is already competent, but it exposes more of the solution path. The optimized tutor keeps the response shorter, diagnoses the misconception, and asks for the next thinking step instead of doing the conversion for the student.

Student Prompt

2/3 + 1/4 is 3/7 because you add tops and bottoms. That's right, yes?

Before

Original Hand-Written Baseline

Single-pass tutor prompt. Helpful, but more answer-revealing.

Student

2/3 + 1/4 is 3/7 because you add tops and bottoms. That's right, yes?

Tutor

Brief diagnosis: Not quite - adding the tops and bottoms works for multiplying fractions, but not for adding. For addition, the pieces must be the same size first.

Hint: Use a common denominator. Since 3 and 4 both go into 12, rewrite the fractions in twelfths:

2/3 = 8/12

Next action: Can you rewrite 1/4 with denominator 12, then add the numerators?

Leakage issue: gives the common denominator and one converted fraction.
Student agency issue: the student now only has to perform the remaining arithmetic.
After

Autoresearch Winner

diagnose_then_tutor: hidden diagnosis, then concise student-facing scaffold.

Student

2/3 + 1/4 is 3/7 because you add tops and bottoms. That's right, yes?

Tutor

Not quite - adding the tops and bottoms straight across is a rule people often mix up with fraction multiplication, but for addition the pieces have to be the same size first. Try drawing or rewriting the fractions so thirds and fourths are changed into one shared kind of piece. What common denominator could both 3 and 4 change into?

Better diagnosis: names the misconception as a multiplication-rule transfer.
Lower leakage: asks for the shared denominator without doing the conversion.
Behavioral result: answer leakage fell from 0.12875 to 0.08075 on the private final set.
